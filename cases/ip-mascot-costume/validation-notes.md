# IP人偶服定制品 Schema 验证记录

## 结论

该案例已达到 `SEARCH_READY`，说明 v0.1 可以承载基础定制材料、工艺、尺寸、重量、预算和相对交期，但暴露了定制品验收与流程表达不足。

## 已验证能力

- 材料、结构和工艺硬约束；
- 目标重量及容差；
- 穿戴人员身高；
- 设计图作为定制输入；
- 1套采购、单价和总预算；
- 从下单起算的最大交期；
- 中国境内交付，并明确排除后续德国物流；
- 原始表述、推导和可信度记录。

## v0.2 改进候选

1. 增加定制流程节点：设计稿提交、3D或效果图确认、开工、半成品确认、成品验收。
2. 增加验收标准：还原度确认主体、参考图、允许偏差、照片或视频证据及返工规则。
3. 增加人体尺寸对象：身高、体重、肩宽、头围、鞋码和适配范围。
4. 明确交期起算事件及是否包含确认、返工和运输。
5. 为预算增加费用包含项，区分含税、国内运费、包装和国际物流。

## 非阻断待确认

- 中国境内具体收货地址；
- 国内运费和税票是否计入5000元；
- 穿戴人员完整尺寸；
- 10kg的允许范围；
- 高还原度的验收和返工机制。
