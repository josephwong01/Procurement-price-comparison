# 咖啡饮料机案例 Schema 验证记录

## 结论

该设备类案例可以由 Procurement Requirement Schema v0.1 表达，并已达到 `SEARCH_READY`。这只代表本案例可以进入搜索，不代表 Requirement Schema 阶段已经结束，也不授权跳到 Query Planner。

## 已验证能力

- 海外展会场景、单台采购和 MOQ；
- 包含运输费用的 TCO 预算上限；
- 咖啡与非咖啡饮料能力分开设定硬约束或偏好；
- 接受低成本速溶粉料方案；
- 上下水未知时优先内置水箱或桶装水；
- `230V/50Hz` 作为待确认偏好；
- 海外配送、电气合规、税费不确定性；
- 用户原文、推导值和可信度 provenance。

## 搜索后仍需核验

1. 预算币种是否为 CNY；
2. 展会具体日期和最晚到货日；
3. 吧台尺寸、最大可用功率及上下水；
4. 饮料菜单和预计杯量；
5. 德国或欧盟适用的电气安全与合规证明；
6. 运费、进口税费、本地税费和耗材成本。

## Schema 边界发现

“最低成本、较高配置、中间平衡方案各选一个”属于候选组合和报告策略，应放入下一阶段的 Search Strategy / Report Strategy Schema。

当前 `required_date` 只能保存具体日期。用户只提供“2026年11月”时，必须使用带警告的临时日期；后续版本可考虑增加 `delivery_window` 表达月份或日期区间。

## 阶段判断

- 需求状态：`SEARCH_READY`
- 本案例具备生成 Query Planner 输入的条件：是
- 项目是否进入 Query Planner 阶段：否；必须先完成阶段 2～5
- 可直接下单：否
- 是否立即冻结 v0.2：否；还需完成标准品、定制品、服务类案例，并汇总改进项。
