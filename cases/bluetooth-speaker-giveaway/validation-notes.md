# 蓝牙音响标准品 Schema 验证记录

## 结论

该案例达到 `SEARCH_READY`。v0.1能够表达标准品基本需求，但“双履约路径”和“标准品可选轻定制”目前只能借助说明字段表达。

## 已验证能力

- 标准品名称、数量、单价和总预算；
- 展会抽奖礼品场景；
- Logo作为偏好而非硬约束；
- 10个的小批量采购与定制MOQ风险；
- 国内包邮与Amazon Germany包邮两条履约路径；
- 国内转运德国费用排除；
- 海外价格原币、税费和汇率记录要求。

## v0.2改进候选

1. 增加 `fulfillment_options`，分别表达渠道、目的地和成本包含项。
2. 区分基础标准品与可选定制项，避免 `customization.required=false` 与定制偏好语义混杂。
3. 增加价格口径：售价、含税、包邮、落地成本及排除项。
4. 增加采购场景字段，使礼品、办公、生产或展会用途不必仅写在描述中。

## 非阻断待确认

- 最晚到货日期；
- 国内和德国具体地址；
- Logo工艺、颜色、位置及文件；
- 最低续航、功率、防水和蓝牙版本；
- Amazon Germany的增值税口径。
