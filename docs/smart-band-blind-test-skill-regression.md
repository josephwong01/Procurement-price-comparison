# 智能手环盲测与Skill修订报告

## 结论

盲测完成了需求补问、平台规划、实时搜索、候选过滤、比价评分和结果留痕。Skill能够在没有历史案例模板的情况下形成候选主表，但本轮状态为`PARTIAL / SHORTLIST_ONLY`，因为预算口径和地址级7天到货尚未最终确认。

## 盲测结果

- 临时推荐：华为手环11 Pro，约¥389/件，2件约¥778。
- 均衡候选：小米手环10标准版，约¥289/件，2件约¥578。
- 低成本候选：荣耀手环10标准版，约¥249/件，2件约¥498。
- 淘宝/Tmall API两轮返回20条，但多数是配件、泛品牌或旧型号，未强行纳入候选。
- Amazon中国未取得稳定零售候选，如实记录为渠道失败。

## 暴露的问题

1. “1000以下”在数量为2时可能表示单价、两件总价或含运费总预算。
2. API返回记录不等于采购搜索有效；原始结果数和相关候选数必须分开。
3. 少量且7天内到货时，批发平台的MOQ和履约风险可能使其不适合作为主渠道。

## 已实施的窄范围修订

1. 多件采购必须区分单价、行总价和全包预算；不清楚时只补问一次，或显式保留可回退假设。
2. Query Planner新增数量、MOQ、目的地和交期对平台选择的影响规则。
3. Adapter执行成功与候选有效性分离；搜索噪声不得充当平台覆盖。
4. 必选平台无有效候选时保留限制说明，不用无关商品凑数。

这些修订只调整Skill决策规则，没有改变前九阶段冻结Schema的字段语义。
