## 责任边界

Query Planner把采购需求转换为平台任务、关键词、筛选条件、访问策略、停止条件与失败降级规则。它不负责实际抓取、商品合格判断、综合评分或主动联系供应商。

## 冻结规则

1. 平台任务是最小执行单元。
2. 用户指定平台标记为 `MUST_SEARCH`，不能被Agent补充平台替代。
3. Agent补充平台限制为1—3个，并使用 `SUPPLEMENTAL_DISCOVERY`。
4. 平台内筛选、查询词筛选、采集后筛选和人工核验必须显式区分。
5. 每个平台独立设置查询语言、访问方式与允许的降级路径。
6. 访问失败可以记录原因后继续；不得把尝试或部分执行表述为完成。
7. 停止搜索同时考虑合格候选数量、价格层级和必搜平台覆盖。
8. 未执行任务的 `execution_result` 为空；执行后记录时间、结果数、详情数、说明和证据引用。
9. 主动询盘不属于Query Planner。
