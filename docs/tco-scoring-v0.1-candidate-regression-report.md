# TCO与综合评分 v0.1-candidate 回归报告

## 覆盖范围

- 咖啡机：欧元原价换算人民币、单列展示、部分TCO和暂定综合分。
- 蓝牙音响：人民币原价不重复显示、定制费未知时暂不评分。
- IP人偶服：页面起始价不作为完整定制TCO。
- 住宅设计：页面入口价不作为150平方米全包服务费。
- 咖啡机最小真实组合：GGM HAS2S、Bosch TAS107E、Nescafé Alegria 6/30。

## 关键断言

1. 外币主表格式为人民币比较价加括号内平台原价。
2. 人民币原价不重复显示括号。
3. 未知成本不按零处理。
4. 汇率、换算时间和原始金额永久保留。
5. 五维权重合计为1，加权分与总分可重算。
6. 信息不足时不生成总分或排名。
