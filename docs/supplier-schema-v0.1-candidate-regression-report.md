# Supplier Schema v0.1-candidate 回归报告

## 范围

- 标准品：展会礼品蓝牙音响供应商。
- 设备：展会咖啡饮料机供应商。
- 定制品：IP人偶服供应商。
- 服务：住宅平面与3D设计服务商。

每类包含一份结构Fixture和一份真实或轻量真实供应商记录，共8份。

## 预期验证点

1. 主体未知时仍可先登记平台店铺，且不会错误声称主体已核实。
2. 店铺评分保存原始量表，并允许形成0—100标准化值。
3. 平台成交信号保存原文，不明统计周期不会被猜测补齐。
4. 公开宣传的定制或服务能力只能标记为 `CLAIMED`。
5. 未询盘信息进入待确认清单，信息不足时不生成供应商总分。

## 验证结果

- Draft 2020-12元Schema检查：通过。
- 四份结构Fixture与四份真实/轻量真实记录：`8/8`通过，零错误。
- 跨字段业务规则校验：`8/8`通过，零错误。
- 校验器：`scripts/validate_suppliers.py`。

## 当前结论

状态：`FROZEN_V0.1`。推荐规则已完成人工确认，结构覆盖四类供应商并通过真实案例回归；8份记录已迁移到正式版本 `0.1`，冻结后复验通过。

## 真实回归边界

- 蓝牙音响、IP人偶服和住宅设计复用既有API采集证据。
- 咖啡机使用GGM Gastro既有公开网页证据，属于轻量真实回归。
- 本轮未主动询盘、未重新核验法律主体、未生成供应商总分。
