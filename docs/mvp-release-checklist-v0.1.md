## 已知边界

- 库存、准确运费、税费、最终交期和定制能力可能仍需供应商确认。
- 淘宝、1688 等平台可能返回噪声、登录限制或只提供区间价格；执行成功与有效候选分开记录。
- 参考汇率允许近似，但必须保留原始币种、参考值和时间。
- 本版本不自动联系商家、不发送 RFQ、不下单、不审批、不写入 OA/ERP。
