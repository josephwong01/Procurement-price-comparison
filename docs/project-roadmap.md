# 项目路线图

## 一、任务定义

输入一个采购需求，Agent自动理解采购参数，制定多平台搜索策略，从公开采购或电商渠道搜集候选商品和供应商，完成商品参数匹配、重复商品清洗、价格标准化、供应商初筛和综合评分，最终输出带原始来源、采集时间、可信度和推荐理由的采购比价表。无法确认的信息必须明确标记，并生成待人工询价或确认清单。

第一阶段止于“形成候选供应商池和初步比价结论”，不自动决定供应商或下单。

## 二、核心能力

1. 商品匹配：判断候选商品是否真正满足采购需求。
2. 数据归一化：统一不同平台的商品、供应商、数量、币种、税费和交付口径。
3. 采购判断：结合匹配度、TCO、供应商可靠度、交期和风险提供决策支持。

## 三、阶段规划

### MVP

1. Procurement Requirement Schema
2. 最终比价表与证据结构
3. 候选商品与供应商统一Schema
4. Query Planner
5. 商品匹配与去重
6. TCO成本及综合评分模型
7. 平台Adapter
8. Skill组装和真实案例验证

|---:|---|---|---|

MVP暂不实现自动聊天询价、自动联系供应商、砍价、下单、审批或ERP写入。

### V1：正式询价闭环

网上初步比价 → 筛选供应商 → 生成统一RFQ → 人工发送或授权发送 → 解析正式报价 → 二次比价 → 推荐供应商。

### V2：采购Copilot

接入历史采购价、企业供应商库、RFQ、风险检查、采购审批与异常报价识别。
