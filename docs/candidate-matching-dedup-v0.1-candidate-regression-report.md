# 商品匹配与去重 v0.1-candidate 回归报告

## 覆盖范围

- 需求匹配：咖啡机、蓝牙音响、IP人偶服、住宅设计各1例。
- 精确重复：同一淘宝商品、店铺和SKU的API与浏览器重复采集。
- 疑似同款：淘宝与京东的妙雀饮料机，品牌相同但京东SKU未锁定。

## 关键断言

1. 硬条件失败才触发自动排除；未知或部分满足不等于失败。
2. 偏好条件失败不会单独排除候选。
3. 精确重复必须是高置信度，才能建议合并比较记录。
4. 同型号不同供应商、不同平台或不同报价必须保留来源和价格。
5. 只有标题或品牌相似时必须进入人工复核，不得自动合并。
6. 去重从不删除原始证据。
