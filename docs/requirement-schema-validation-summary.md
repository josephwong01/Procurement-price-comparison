## v0.2必须处理

1. 日期窗口和交期起算事件；
2. 多履约路径及成本边界；
3. 费用包含项与排除项；
4. 标准品可选轻定制；
5. 定制流程、确认节点与验收规则；
6. 服务范围、客户输入、交付物、里程碑和修订政策；
7. 知识产权、源文件及保密要求；
8. 采购使用场景和适用对象。
