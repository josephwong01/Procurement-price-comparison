## 范围

Skill 入口：`skills/procurement-sourcing/SKILL.md`。

## 端到端回归

咖啡饮料机案例以历史真实采集产物进行编排回放。清单覆盖八个必需阶段，所有底层校验器由统一入口调用。

本次状态为 `PARTIAL`，原因不是流程失败，而是不同开发阶段的历史记录使用过不同候选ID，且库存、精确运费、最终交期和供应商确认尚未完成。因此本轮证明“流程可串联、合同可校验”，不宣称完成了一次全新的实时询源。

统一校验入口：`python scripts/validate_end_to_end.py`。

## 人工审阅点

1. 最终推荐前确认硬性规格与未决成本。
2. 供应商声称、库存和交期在正式采购前询盘确认。
3. `PARTIAL` 或 `FAILED` 必须原样进入最终报告，并列出未完成事项。
4. MVP仍不自动联系供应商、不下单、不审批、不写入OA/ERP。
