## 关键断言

1. 用户指定平台不会被补充平台替代。
2. 平台不支持的硬约束转为采集后筛选或人工核验。
3. API、公开网页、浏览器和截图的降级顺序按平台记录。
4. 定制品与服务类的入口价不会被Query Planner当成全包价。
5. 主动询盘不属于本阶段；需要询盘的信息只形成后续人工核验条件。
