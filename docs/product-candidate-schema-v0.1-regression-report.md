## 回归中发现并修复的问题

移除履约方案后，定制品和服务类仍需要表达交期及其起算点。本轮新增并经人工审阅精简后的 `offer.commercial_terms`，用于记录：

- 交期天数；
- 交期起算事件；
- 售后；
- 付款条件；
- 报价有效期。

这些字段属于当前供应商报价条件，不用于拆分 Candidate，也不恢复独立履约方案。库存和保修按人工审阅结论暂不纳入本版Schema。
