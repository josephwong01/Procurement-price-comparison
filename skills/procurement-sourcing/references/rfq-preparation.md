# RFQ preparation

Use this reference only after a shortlist exists and unresolved supplier facts affect eligibility, TCO, delivery, or risk.

## Output

Prepare one shared question set plus candidate-specific questions. Each question records:

- stable question ID;
- topic;
- exact question;
- expected answer type;
- whether it blocks final recommendation;
- current answer status;
- evidence or attachment requested when relevant.

Also create a blank answer sheet so manually received answers can be entered without rewriting the candidate records.

## Question design

- Ask one fact per question and state the exact SKU/model.
- Prefer verifiable values: voltage/frequency, plug, water source, hourly throughput, packed size/weight, unit price, lead time, warranty, and document names.
- Separate product capability from commercial terms.
- Do not ask again when a reliable source already confirms the fact, unless purchase-time reconfirmation is necessary.
- Keep freight and tax estimates marked as estimates until a quote or carrier calculation replaces them.

## Human boundary

Produce files for a person to copy, send, and populate. Never open a chat, send a message, submit a form, or disclose buyer data. Later automation requires a separate user decision and authorization model.
